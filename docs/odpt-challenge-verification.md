# ODPTチャレンジ2026 認証データの確認

同名駅は路線ごとに数える。既存の236駅・路線と合わせ、検索対象は1,642件。発車時刻の合計は、平日・土休日・特別開催日などの元表を合算した検証件数であり、1日分の列車本数ではない。路線名と駅数はアプリの「対応路線とデータ」に事業者ごとに表示する。

`node scripts/check-odpt-challenge.mjs` は、正規化側の変換関数と別の処理で、全原資料の駅・方面・運行区分・発車時刻の多重集合を照合した。00時〜03時台の翌日表記と、秒付き時刻を保持した。上流APIの1,000件の取得上限に達したJR東日本は路線ごとに分割取得し、全2,688表を確認した。

京王の競馬場開催日106表は、ODPTの `Calendar` に明記された19日とその確認期間を使う。対象日は開催日用の表を通常表に優先し、日付を確認できない特別ダイヤを曜日から推測しない。同時刻・同じ行先の別列車は元資料の列車番号で区別した。東急の共有駅は、駅情報が明記する時刻表へのリンクで解決した。

JR東日本には行先の記載がない発車が28,006件あり、「行先未確認」と表示する。他の7事業者の行先名の参照未確認は0件。元データにない情報を駅名や英字識別子から推測して補ってはいない。JR東日本の提供範囲は関東の一部の在来線で、全国・新幹線・全列車を含むという意味ではない。

実データで8事業者それぞれの検索・駅選択・お気に入り登録・時刻表表示をブラウザーで確認し、再読込後のお気に入り保持も確認した。2026-10-23〜25について4,208駅日分のサーバー側変換出力がクライアントの検証に通った。JR東日本の残る10駅日分は利用可能な表がなく、別の日の時刻表で代用しない。京王の2026-10-24開催日ダイヤは、実際のHTTP APIから取得した59駅・方面の表が、元の開催日用データと一致した。

取得原資料・正規化キャッシュ・詳細照合結果・画面画像はGit管理対象外へ保存した。公開リポジトリやフロントの配信ファイルにトークン・取得した限定時刻表を追加していない。入力画面からWindows DPAPIで暗号化保存し、同じWindowsアカウントで復号できることは、別の一時フォルダーと架空トークンを使ってPC・スマホ相当のブラウザーで確認した。

再現手順と本番用設定は [非公開設定手順](odpt-challenge-setup.md) を参照。提供期間終了後の停止・キャッシュ削除、6時間の再確認、年末年始・遅延・運休・駅入口の未確認という制約は同手順のとおり。
