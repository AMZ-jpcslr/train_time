カタログで [CC BY 2.1 JP](https://creativecommons.org/licenses/by/2.1/jp/) を明示している。権利者・出典・ライセンスリンクと加工した旨をデータの `notes` と本書に記載。公式のロゴ、画像、レイアウトは複製していない。このオープンデータの許諾を他の事業者のデータへ拡張していない。

駅別の公式HTMLページは今回の閲覧ツールで403となったため、その制限を迂回せず、別途公開された公式オープンデータから通常のHTTP取得で入手した。元CSVは `.cache/municipal/` にローカル保存し、Git管理・配信アセットから除外。画面更新で時刻表サイトへアクセスしない。

### 再取得・検証方法

```powershell
# 保存済み原資料を通信なしで再解析。確認日時は更新されない。
# キャッシュがない場合は --refresh を要求する。
node scripts/import-municipal.mjs

# 公式カタログのリンクと版を再確認後、4 CSV を各1回取得。
# 通信間隔1.2秒。HTTPエラー時に迂回や自動再試行はしない。
node scripts/import-municipal.mjs --refresh

npx vitest run tests/municipal.test.ts
```

Shift_JISを明示デコードし、CSVヘッダー・列数を検証。駅の行と行先駅の行を同じ列で対応付ける。午前0～3時を24～27時へ正規化し、前の運行日へ所属させる。各表の始発・12時台・終電を取得原CSVから独立に転記した固定照合値と比較する。件数・欠損・重複・時刻順も検査する。照合値が変わった場合は自動採用を止め、元資料の再確認が必要。全便を別資料と一件ずつ突き合わせたわけではない。

`verified` は上記の機械検査と始発・日中・終電のサンプル照合の完了を意味する。全便目視・運行保証・将来の現行性保証を意味しない。CSVの発車事実を採用し、駅別PDFの色・記号の復元は行っていないためPDF列ずれを起点とする補完もない。

### 適用日・特定日・未検証範囲

公式掲載の改正日を `revisionDate` / `validFrom` に保存。適用終了日は未公表のため `validTo: null`。これは将来まで使用できる保証ではない。アプリ側の30日再確認期限は、事業者が示した適用終了日やライセンス期限とは別の自主的な鮮度制限。

原資料は平日と土曜・休日の定型時刻表。祝日はアプリの日本祝日データで選択する。特定日の臨時運転・増発は未収録。神戸市交通局の[2025年末～2026年始の公式告知](https://kotsu.city.kobe.lg.jp/news/information/bus/2025winterholiday/)は地下鉄12/29～1/2を土休日とするが、これを2026年末へ一般化しない。2026年末や将来のお盆などの個別告知は未検証。初期アプリは12/29～1/3の判定を停止する。任意の催事や臨時変更をすべて収集する仕組みはない。

## 京都市営地下鉄 今出川：公開HTMLを参考収録（現行性確認が保留）

追記（2026-10-22）：無料公開時刻表を読み取る方針に基づき、原HTMLを再取得して4表610本を `src/data/kyoto.json` に収録した。全表 `partial`、参考発車表示のみで徒歩乗車判定には使わない。現在の取得方法、条件、17解析テスト、サンプル照合証拠は [kyoto-sources.md](./kyoto-sources.md) と [kyoto-validation.json](./kyoto-validation.json) を参照。以下はこの方針決定前からの調査記録である。

次の公式情報を調査した。

- [駅の入口ページ](https://www2.city.kyoto.lg.jp/kotsu/tikadia/hyperdia/menu0216.htm)
- [南行 HTML](https://www2.city.kyoto.lg.jp/kotsu/tikadia/hyperdia/021600.htm)、[北行 HTML](https://www2.city.kyoto.lg.jp/kotsu/tikadia/hyperdia/021601.htm)：平日・土休日の各時刻、南行の新田辺／近鉄奈良などの行先符号を確認できた。ただし個別表の「令和7年02月22日現在」と、[トップページ](https://www2.city.kyoto.lg.jp/kotsu/tikadia/tikatime.htm)の「2026年3月14日以降」との版の整合を確証できなかった。
- [京都市営地下鉄時刻表・2026年3月14日近鉄ダイヤ変更（データセット00692）](https://data.city.kyoto.lg.jp/dataset/00692/?page=1)：検索結果で、烏丸線の平日／土曜・休日×上り／下りの4 CSV、および **CC BY 4.0** の明示を発見。実際のアクセスはメンテナンスページへリダイレクトし、原CSVのリソースURL・内容を取得できなかった。検索結果だけでCSVを推定しない。
- [ハイパー地下鉄ダイヤの利用案内](https://www2.city.kyoto.lg.jp/kotsu/tikadia/guide/about.htm)は[京都市の著作権・リンクの考え方](https://www.city.kyoto.lg.jp/main/site_policy/0000000005.html)へ誘導しており、同ページは法令で認められる場合を除く無断複製・転用を認めていない。HTML一式や編集構造の複製は採用せず、明示ライセンスのあるCSVを優先する。個別の発車事実が一律に著作物だとも、数字だから無条件に利用できるとも判断していない。
- [ODPTチャレンジ2026](https://challenge2026.odpt.org/)で京都市営地下鉄が2026-07-03に公開されたことを確認。期間限定の枠や登録・API条件があるため、アカウント登録も認証回避もしていない。コンテスト期間（2026-07-01～2027-03-12）をデータそのものの利用期限と同一視していない。詳細なデータ利用期間・終了後の保持条件は未確認、未採用。

今回の今出川データは公開HTMLの実際の発車事実であり、デモではない。一方で公式トップと個別ページの日付不一致は解消できていないため、現行性未確認の表示を付けて参考発車に限る。ポータル復旧後に00692のCSV・ライセンスを実取得するなどして適用期間を確認できるまで、徒歩乗車判定は停止する。
