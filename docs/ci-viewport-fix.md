## 確認した失敗

- 対象: `fd61755c9728a3c085a312bef363a1094e59fe83`、[Check #39885414138](https://github.com/AMZ-jpcslr/train_time/actions/runs/39885414138)。
- Linux / Chromium / 1280×720の `review-regression.spec.ts` で、`.stay-deadline` の下端が725.109375pxとなり、初期画面内に収まる条件に失敗。ブラウザ試験は99成功、1失敗、2スキップ。
- 失敗時のtrace画像でも「14:04:00 までに今の場所を出発する目安」の末尾が2行目へ折り返し、下端から切れていた。画面内表示に関するP1。ローカルWindowsでの以前の成功だけではLinuxでの表示を保証できていなかった。

## 修正

`StayTime.tsx` の文言を「今の場所を出る目安 14:04:00」に短縮。登録地点の場合は「登録地点を出る目安」とする。場所の区別、時刻の秒表示、文字サイズ、44px操作領域、計算式は維持する。折り返し禁止や省略表示は使わず、文字拡大時は自然に折り返す。

`stay-time.spec.ts` は現在地の文言と時刻をまとめて検証。`review-regression.spec.ts` は画面高720pxの既存条件を維持し、失敗時に対象selectorと上下端の区別が分かる診断メッセージを追加。
