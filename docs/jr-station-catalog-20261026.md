## 一括変換とレビュー

`scripts/import-jr-station-catalog.mjs`はネットワーク取得を行わず、保存済みGeoJSONと`jr-station-catalog-review-20261026.json`を読み込む。会社=西日本旅客鉄道、原路線=東海道線・山陽線・北陸線をフィルタし、レビュー済み所属名に一括突合する。座標を駅ごとに手入力しない。

レビューはJR公式[停車駅案内](https://www.jr-odekake.net/station/pdf/teisya_01.pdf)と[近畿路線図](https://www.jr-odekake.net/station/pdf/ubn.pdf)の2026-03-14改正版を画像で確認したもの。77駅名と駅順を照合し、N02欠損は0。PDFそのものはローカル参照に限り、公開するmanifestには駅所属という事実、出典URL・版・ハッシュ・確認日時だけを記録する。時刻、曜日、列車方面、入口の確認ではない。

元87地物は大阪5・米原4・神戸2・兵庫2・新大阪2の複数形状を含む。正規化内容SHA256と予定地物数を照合し、未知の重複・完全重複・欠損・不正コード・不正座標・未レビュー所属は停止する。JSONの空白・改行・地物順の違いは無視するが、属性や座標変更は停止する。確認日を実行日で自動更新しない。

N02の駅は線形状。複数形状の頂点平均を検索表示用代表点にし、`coordinateKind=station-representative-not-entrance`を付ける。入口、徒歩ルート、乗車判定の根拠にしない。N02グループコードは同名300m内の他社駅も含み得るためphysicalStationIdに流用しない。IDは当該駅の最小N02駅コードと路線slugから作成。版更新で元コードが変わった場合は差分に出し、既存保存設定への移行を別途検討する。

福島は東海道線支線、和田岬は山陽線支線として元資料に含まれるが今回の所属に含めない。神戸・米原の原路線境界、京都・大阪の愛称境界を別扱いする。長浜以北・姫路以西は対象外。

`directions:[{id:'unavailable',name:'方面は未対応'}]`は内部の空状態表示用で実方面ではない。`catalogOnly:true`、codeは`JR`。駅番号や列車の方面を線形状から推測しない。既存情報へのリンクはJR公式トップ `https://www.jr-odekake.net/`。確認された駅個別URLを新規に推測・構築しない。

## 再生成・更新

```sh
node scripts/import-jr-station-catalog.mjs
npx vitest run tests/jr-station-catalog.test.ts --maxWorkers=2
```

初回追加差分は`jr-station-catalog-diff-20261026.json`。同じ入力の再実行では出力が同一で、初回差分を消さない。新原本を使うときは別ファイルを指定する。

```sh
node scripts/import-jr-station-catalog.mjs --source docs/new-source.json --review docs/new-reviewed-membership.json --output .cache/new-catalog.json --diff .cache/new-catalog-diff.json
```

新原本の取得URL/日時/ハッシュ/利用条件を保存し、所属・新設・改称・廃止・境界・支線・重複を人がレビューしてから新manifestのcheckedAtと選択地物SHAを固定する。ソースやレビューのハッシュ不一致を直すためだけに、機械的に承認ハッシュを書き換えない。旧版と新規版のID・座標・所属差分を確認してから接続する。
