### 公式案内との照合範囲

[神戸市交通局 学園都市駅](https://kotsu.city.kobe.lg.jp/subway/timetable1/gakuentoshi/?type=free) の本文で、駅番号 **S14**、地上1階に改札1箇所、地下1階の1番線は総合運動公園方面・2番線は伊川谷方面、階段・エレベーター・エスカレーターで移動できることを確認した。この本文は改札と両方面の接続を裏付けるが、出口の測量座標を提供するものではない。

公式構内図画像は未照合。Web 読み取りでは本文を取得できたものの画像リンクが抽出されず、通常 HTTPS 取得は 202 の空本文、ブラウザーは利用不可だった。認証・アクセス制限の迂回や URL の推測は行っていない。したがって **公式構内図を目視照合済みとは扱わない**。駅探の出口名称・座標の対応は確認済みだが、現地測量と歩行経路の終端接続は未検証である。

駅番号は [神戸市オープンデータ「地下鉄各駅 所在地・電話番号一覧」](https://catalog.city.kobe.lg.jp/dataset/3541-5-2-2-2-f6a28b58cd4c8777-6741f3e3e026f2c8/resource/0bbd07bf-c8fd-4c5e-87f5-ca6b0cc78cf1)（2026-03-05 更新）でも確認した。CSV の学園都市は **S14**、妙法寺は **S11**。ローカル確認原本は `.cache/osm/context/kobe-station-addresses.csv`。この一覧は所在地を示す資料で、入口座標の出典ではない。

### OSM 地物との照合範囲

既に取得済みの `.cache/osm/context/gakuentoshi-map.json` を使用した。追加の Overpass リクエストや OSM 編集 API へのアクセスは行っていない。

- 両出口座標は駅建物 [way/196468561](https://www.openstreetmap.org/way/196468561) の東端に位置する。その東側数 m に橋上歩道 [way/1299449718](https://www.openstreetmap.org/way/1299449718) があり、駅へのアクセス位置として整合する。
- OSM 内に当該出口を示す `railway=subway_entrance` node、当該歩道から改札へ至る明示的な接続は確認できなかった。建物の角 node を出口として転用していない。
- 駅中心 node/3903196858 と、駅南側商業施設の可能性がある近隣入口2点は採用していない。
- 座標から歩道への数 m の接続を自動的に実測経路とみなさない。経路が取れても、入口から改札・ホームまでの時間は別に加算する。

### 更新と利用条件

`scripts/reviews/gakuentoshi-entrances.json` は原文 SHA、取得日時、抽出条件、除外理由、確認済み範囲を持つ追加入力。`entrances` 配列は既存入口データと同じ `id / stationId / name / lat / lon / sourceUrl / checkedAt / note` を持つ。再取得時は通常 HTTPS で出口ページと iframe を1回ずつ読み、4マーカーのうち ID 534 / 533 と名称・WGS84 の対応を確認する。本文や座標が変わった場合は自動承認せず再レビューする。画面のカウントダウン時には取得しない。

[駅探利用規約](https://ekitan.com/help/rules/terms) の情報蓄積・加工・再利用に関する条件は別途確認が必要。無料閲覧できることだけを、データベースの複製や再配布の許諾とは解釈しない。今回の入口の個別事実とサイト全体の編集物を区別し、ロゴ・地図画像・デザインはアプリへ転載しない。外部公開・商用配信の許諾を取得済みとは扱わない。
