# 駅案内端末UIの利用経路

`/` が採用した券売機・発車案内・紙の切符を組み合わせた実用画面です。通常の時刻表取得、方面/種別条件、便の手動選択、登録地点、お気に入り、日時指定、データの鮮度制限へ接続しています。固定の比較用ダイヤは使用しません。

- `/railway.html`：同じ実用画面への直接入口。
- `/classic.html`：従来画面を残した互換用入口。既存機能の回帰テストはこちらを明示して実行します。
- 未採用の比較画面、画像、ローカル検証ログは本リリースに含めません。

## 徒歩時間と位置情報

「徒歩入力」で上下の数字ホイール、矢印キー、直接入力から0〜240分を選択できます。30秒追加にも対応し、設定ボタンで確定します。駅入口からホームまでの余裕は別に設定します。

「位置情報」は利用者が更新開始を押した場合だけ継続取得します。既存の設定済み徒歩経路サービスを使用します。停止、手入力確定、駅/方面/入口変更、画面を離れる操作で解除し、自動再開しません。誤差50m超または45秒より古い位置では目安を止めます。GPSで乗車は確認できません。

表示便の予定発車後に次の便へ変わる場合だけ短いパタパタ表示を行います。高精度の位置を継続取得して駅入口付近と推定した場合は一度だけ切り込みを表示します。reduced-motionでは不要な動きを抑えます。遅延・運休のリアルタイム追跡は追加していません。

補足説明は出典/計算/設定の詳細へ整理しています。期限切れ・参考時刻・GPS拒否/低精度・経路取得失敗の制限は、該当状態で表示します。

## ローカル確認

`npm ci`、`npm run dev` の後に表示されたURLの `/` を開きます。既存の経路サーバー設定がない場合は手入力が使えます。秘密値をクライアントへ追加しないでください。

- `npm test`
- `npm run build`
- `npm run check:package`
- `npx playwright test`：従来機能の互換画面回帰
- `npx playwright test --config playwright.railway.config.ts`：採用画面のトップページ、徒歩入力、継続位置更新、便選択、文字コントラスト、主要幅
- `npx playwright test --config playwright.pwa.config.ts`：production buildの更新/オフライン

ブラウザーテストは模擬位置・模擬経路・取得済み時刻表fixtureを使います。実機で歩いた検証や屋内GPS精度、スクリーンリーダーによる操作は別途確認が必要です。
