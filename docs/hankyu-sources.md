# 阪急3駅：現行通常ダイヤの確認

2026-10-22に現在掲載される公式駅ページ、改正告知・FAQ、HTMLとPDF版情報を追加確認した。3駅・両方面（大阪梅田は神戸線西行のみ）・平日／土曜休日の10表1690便を通常ダイヤとして使用し、徒歩乗車判定を有効にした。

## 根拠と意味

- [公式改正告知](https://www.hankyu.co.jp/topics/detail/013718.html)は神戸線・宝塚線について2025-02-22初発からの改正を明示。
- [現在掲載の公式FAQ](https://faq.hankyu.co.jp/category/show/13?site_domain=default&sort=sort_new&sort_order=desc)のNo.1801も同改正を案内している。
- [六甲](https://www.hankyu.co.jp/ch/station/rokko.html)と[神戸三宮](https://www.hankyu.co.jp/en/station/sannomiya.html)の公式駅ページを読み、通常表と「2月22日以降」改正版の方面・曜日リンクを確認。[大阪梅田](https://www.hankyu.co.jp/station/umeda.html/)も公式の検索取得本文で両版を確認した。改正版のリンク先は20250222配下であり、先頭の無日付リンクを日付根拠として採用していない。
- 無日付PDFの取得結果・検索取得本文にある文書タイトルで、六甲上り平日／土休日、下り平日／土休日、神戸三宮上り土休日・下り平日／土休日、大阪梅田下り平日／土休日の2025-02-22改正版を確認した。神戸三宮上り平日のPDF自体は502で取得できず、この1表は公式現行導線・全線告知・FAQ・HTML構造と原資料サンプルを根拠とする。
- 六甲の版付きHTML（上り土休日、下り平日／土休日）の取得できた範囲と、無日付の収録時刻に矛盾がないことを確認した。保存できた連続行の自動比較では上り土休日58便・下り土休日66便の時刻／行先／種別が全一致（.cache/hankyu-current/revision-comparison.json）。全10表の始発・日中・終電・件数の原文照合は既存の独立サンプル検査を再実行した。

verifiedは「現行公式導線、掲載版情報、表の構造と固定サンプル照合済」という意味であり、臨時列車や全便の別資料突合まで完了した意味ではない。全線改正告知と版資料に基づくrevisionDate/validFromは2025-02-22。終了日未公表のためvalidToはnull。個別PDFのタイトルは版の確認にのみ使用し、PDFの色から全列車の種別を抽出したとは扱わない。

## 再実行・更新

- node scripts/import-hankyu.mjs — オフラインの原文再解析。
- node scripts/import-hankyu.mjs --refresh — 明示した公開出典だけを各1回、1.2秒間隔で取得。旧原文をhistoryに保存。
- npx vitest run tests/hankyu.test.ts — 3言語・深夜・未知記号・欠損・原文見出し・現行版照合を検査。

通常HTTPSはこの環境で502となるものが多く、web閲覧ツールが返した公式ページテキストを保存している。認証や制限の迂回はしていない。取得時刻はweb閲覧取得時点であり、元サイト更新日時やキャッシュ生成時刻ではない。

[scripts/reviews/hankyu-current.json](../scripts/reviews/hankyu-current.json)には追加調査日時、一次資料URL、証拠ファイルのSHA、各表の発車事実SHAを保持する。取込時に全便の事実SHAと出典URLが一致する場合だけこの版確認を再利用する。将来時刻が変わった表はpartialへ戻す。checkedAtは原表取得と現行性確認の古い方を使用し、再解析や新規取得だけで現行性確認日を伸ばさない。30日の鮮度期限を過ぎれば再調査が必要。秒単位の画面更新は時刻表取得を伴わない。

## 未対応・利用条件

行楽・イベント・正月の臨時ダイヤは原駅時刻表自体が非対応と明記している。遅延・運休は未反映。年末年始は別途アプリが判定を止める。全便PDF独立比較、全特定日変更、ホーム番号は未確認。

各HTML末尾には阪急・駅探の許可を得ない加工・再利用・再配布等を認めない個別条件がある。[サイトポリシー](https://www.hankyu.co.jp/sitepolicy/)に加え、この条件も未解決事項として保持する。事実と創作的構成・データベース・契約条件を区別し、無料公開やローカル試作だから無条件に利用可能とは判断しない。今回の変更は技術上の現行性検証であり利用許諾の取得ではない。一般公開・再配布・継続利用の確認、登録・契約・問い合わせ・公開デプロイはしていない。
