# 西日本各社の駅検索・時刻表API接続

2026-10-25。JR西日本・阪急・阪神の追加検索をTransit APIへ接続した。従来の照合済み8駅の時刻表は維持する。追加分は非公式APIの参考表示であり、現行ダイヤの照合済みデータとは扱わない。

## 利用方法と範囲

乗車駅の検索で「JR西日本 高槻」「阪急 十三」「阪神 西宮」などを入力し、「JR西日本・阪急・阪神の駅も検索」を押す。候補の路線を確認して選択・お気に入り登録できる。駅名・路線・出典等の選択／お気に入りメタデータは端末に保存し、再読み込み後も復元する。時刻表をローカルの恒久データとして蓄積しない。

対象フィードはJR西日本43、阪急1、阪神2。対応路線の一覧はアプリの「対応路線とデータ」に表示する。全国検索APIの候補上限は30、事業者で絞り込んだ後の追加候補上限は8。網羅的な全駅台帳ではなく、APIが返す駅を利用時に追加する。新規フィードの採用は `server/western-feeds.json` の更新が必要。

## APIと取得制御

- 固定配信元 `https://api.transit.ls8h.com` の検索・駅詳細・発車APIのみ使用。認証情報は不要。ODPT由来で発車一覧の提供を制限するフィードは対象外。
- 駅識別子を検証し、固定のフィード一覧にないもの、URL・パスの混入、別駅・別運行日・異なるタイムゾーンの応答を拒否する。
- 100便ずつ時刻境界を含めてページ取得し、列車ID・停車ID・秒数で重複排除する。同時刻で進めない場合や20ページの上限では一部取得であると注記する。
- 固定の発車時刻がない頻度運行は展開しない。4:00～翌27:59の取得範囲とし、翌日未明の便の網羅は未確認。指定日に空なら公式情報へ案内する。
- 発車表は1時間、検索・駅詳細は6時間の共有Redisキャッシュ。取得は共有スロットで1.1秒以上間隔を空け、同じ取得はまとめる。公開版で共有キャッシュがない場合は停止する。
- 原時刻表と応答の検証記録はGit管理対象外の `.cache/verification/western-*.json` に保存。公開リポジトリには原時刻表を追加しない。

原典：JRおでかけネット、阪急電鉄公式時刻表、阪神電気鉄道公式時刻表PDF。駅の表示名・実際の対応路線はAPIの駅詳細から取得し、原典URL・帰属・原資料取得日は各表の出典欄に表示する。駅中心座標を入口とみなさず、入口未収録駅の自動徒歩計算は行わない。
