## 実データの取得元と検証

利用者入力ではなく、[駅探の公開甲子園時刻表](https://ekitan.com/timetable/railway/line-station/335-13/d1) の平日 `?dw=0`・土曜 `?dw=1`・休日 `?dw=2` をそれぞれ通常HTTPSで取得。これらのパラメータは実際の公開UI内の曜日選択処理で確認した。各HTMLに両方面の表が含まれる。駅ID `5257`、路線ID `20700`、駅路線ID `335-13`、方面を検査し、日付指定表を通年パターンに一般化していない。

- 時刻・行先・種別は表示テキストと `data-dest` / `data-tr-type` を照合し、時刻と方面を公開列車リンクの値でも照合する。
- `普通`、`直通特急`、`特急`、`急行`、`快速急行`、`区間急行`、`区間特急` を区別する。神戸三宮・新開地・山陽姫路・東須磨等の行先を方面とは別に保持する。
- 当駅始発は属性と下線クラスの一致を確認して注記に保存する。ホーム番号は資料にないため `null`。
- 0時台は前運行日の24時台に正規化。行の欠損、順序、重複、未知の種別/行先記号を拒否する。
- 土曜と休日は別取得し、全便の時刻・行先・種別・注記が一致した場合だけ `weekend` にまとめる。
- [Yahoo東方面](https://transit.yahoo.co.jp/timetable/26350/4231) と [Yahoo西方面](https://transit.yahoo.co.jp/timetable/26350/4230?kind=1)、それぞれ土曜 `?kind=2` の別公開資料と **全1,224便の時刻・種別・行先が一致**。駅名の「(阪神線)」「(兵庫県)」等だけ明示的な対応表で正規化した。Yahooは照合用で、曜日/運行条件の根拠は駅探の標準曜日表および公式標準発車表。
- 公式PDFの固定サンプル: 東は両曜日とも05:01大阪梅田・12:02大阪梅田・24:29尼崎。西は両曜日とも04:45新開地・12:09西宮・24:33御影。**公式PDF全便の色・囲み記号との照合は未実施**。発車数は完全HTML同士の照合値でありPDF画像から数えた値ではない。

改正日は全資料で2025-02-22が一致し、公開現行標準ダイヤとして `verified` にした。適用終了日は未公表のため `null`。将来のダイヤ改正を自動的に承認しない。野球開催日の増発、臨時停車、ホーム変更、特別日の変更は未収録。通常の祝日選択と年末年始の判定停止はアプリ共通の処理に従う。

## 更新・再現

```powershell
node scripts/import-hanshin.mjs
node scripts/import-hanshin.mjs --refresh
npx vitest run tests/hanshin.test.ts
```

通常実行は `.cache/hanshin` の保存HTMLとURL・取得日時・SHA-256を検証して再解析するだけで通信しない。`--refresh` は駅探3ページ、Yahoo4ページを1.2秒間隔で通常HTTPS取得する。アクセスエラー時は停止し、認証・制限回避や自動連打をしない。旧キャッシュは `history` に保存。新改正日、固定サンプル/件数の変化、土曜と休日の差、資料間不一致は出力を更新する前に停止する。

出力は `src/data/hanshin.json`（4表1,224便）と `docs/hanshin-validation.json`（出典・取得日時・ハッシュ・全便照合数）。キャッシュ再解析では `checkedAt` を延長しない。今後の改正時は公式PDF/駅ページを再確認して固定サンプルも更新する必要がある。

2026-10-22の専用テストは13/13成功。オフライン再解析前後の `hanshin.json` SHA-256 は `ae246cdd281598d0ab02b40ee144ca6728976cfef3088535ce51ea365c3691e2` で一致した。

個々の時刻という事実と、提供事業者の編集物・データベース・契約条件を区別する。このローカル実装は利用許諾が確認済みという意味ではなく、継続的なサービス利用、保存、再利用、一般公開・配布の許諾は未確認。第三者への公開・問い合わせ送信・契約は実施していない。元サイトのデザイン・ロゴ・画像はアプリに含めない。

## 駅位置・入口

一覧の駅中心座標は公開Yahoo駅資料の `Geometry`（34.723885389295,135.36328477529）から概略値を採用。**この座標を入口とみなさない。** [公式構内図](https://www.hanshin.co.jp/uploads/guidemap/koshien.pdf) は2026-02-01現在、東口・西口、各方面ホームへのエレベーター接続を確認できるが、地理座標は載っていない。入口までの徒歩ルートは別途確認した入口データを使う。

駅入口取得処理がOpenStreetMapの2入口を確認し `src/data/entrances.json` に保存済み。東側 [node/7627826584](https://www.openstreetmap.org/node/7627826584) は34.7234746,135.3633398、西側 [node/13382690030](https://www.openstreetmap.org/node/13382690030) は34.7237702,135.3628778。臨時出口は採用していない。地理座標はOSM、両方面ホームへつながる改札の確認は公式構内図という別々の根拠である。
