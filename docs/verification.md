E2Eは2026-10-22 14:00 JSTに時計を固定し、必要なシナリオで10/23・24・11/3などへプレビューを切り替える。時刻表は取得した実データ、位置情報・80m/60秒の経路応答は固定テスト値。画面の徒歩1分は現地実測結果ではない。実API疎通とは別試験で、外部サービスへの要求を遮断する。利用者用ブラウザーには模擬位置・試験登録地点を保存していない。

- 今出川両方面、阪急3駅全5方面、甲子園両方面で、位置操作→入口→経路→徒歩時間→5本の判断まで確認。
- JR4駅8方面について10/23・24の別日表を表示。大阪西の宝塚・新三田行が消え、茨木からJR京都線を通る直通便は維持。10/26はテスト応答を明示的な未取得にして、別日の表で代用しないことを確認した。実サービスが10/26を取得できないという意味ではない。
- 位置拒否時の登録地点保存、5分超の古い位置、精度100m超、未来・不正座標、道路経路失敗・混雑・異常形状、自動車・フェリー混入を検証。
- 駅変更中の旧経路を判定に使わず、取得中・失敗は判定不可。徒歩速度、構内移動、安全余裕の変更を反映。
- 祝日11/3の土休日表、年末特別日の停止、24時台、発車1秒前と発車時刻ちょうど、終電後、画面復帰時の再計算、30日期限切れを検証。過去プレビューへ戻しても期限切れは解除しない。
- PWAはオフライン起動、期限内のJR同日保存データ、今出川の検証済み表を確認。新しい徒歩経路は捏造せず判定不可。JR保存データの6時間失効を確認。

## 実サービスの確認と残る境界

[経路疎通記録](routing-live-validation.json) は6駅の成功に加え、JR桜橋付近のNoSegmentと初期バックオフ失敗を残している。道路に接続しない現在地の400を、全利用者・全駅の混雑と誤扱いしていた処理を修正し、別地点で再試行できる回帰テストを追加した。すべて公開駅近傍の試験座標であり、利用者の現在地や実測歩行ではない。

[ローカル実行記録](local-runtime-validation.json) は再起動したpreview APIの4日分、連絡先設定、開発時の `.env.local` / `.cache` 403、キャッシュ書込後の稼働を確認する。`verify-local-runtime.mjs` は10/22の取得済み4日分を対象にする確認スクリプトであり、通常の日次更新は `/api/jr` または `npm run data:jr -- --refresh` を使う。

次の範囲は未取得・未検証または対象外として残る。

- 阪急神戸三宮東行平日の公式PDF直接取得、阪神公式PDF全便の色・囲み記号の画像照合は未完了。他の公開資料・公式現行導線で確認できた範囲を超えて検証済みとしない。
- 学園都市の公式構内図画像は未照合。全11駅の全入口・開閉時間・バリアフリー、すべての入口の実経路接続は未網羅。22入口すべての現地歩行試験は行っていない。
- JR大阪の別掲特急・環状線・宝塚線、臨時列車・野球開催時の増発／臨時停車、年末特別ダイヤ、遅延・運休は未対応。公開されていない将来日や取得失敗日は表示・判定を停止する。
- JR・阪急・駅探等の保存・加工・継続利用・再配布に関する許諾確認は未解決。公開されている数字だから無制限利用できるとは扱わない。一般公開用の権利確認済みデータではない。
- 経路は無料のローカル試用接続。1.1秒間隔、30回/時・120回/日、10分キャッシュ。無制限の本番利用、サービス可用性、現地の移動時間・乗車成功は保証しない。
- 実機PWAインストール、iOS/Androidネイティブアプリ、ホーム画面ウィジェット、外部公開は未実装。契約、登録、問い合わせ送信、Git commit/push、一般公開デプロイは行っていない。
