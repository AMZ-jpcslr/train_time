## 出典・利用条件・確認の範囲

公式[地下鉄オープンデータ](https://kotsu.city.kobe.lg.jp/company/overview/open-data/subway-opendata/)の検索経由表示は、西神・山手線/北神線を2025-03-15改正、海岸線を2026-03-14改正と明記している。同ページは CC BY 2.1 JP を明記する。今回の原CSVは神戸市の[公式カタログAPI](https://catalog.city.kobe.lg.jp/api/3/action/package_show?id=f2d416e9-7dae-4938-b62e-7c717002d715)が返した4ファイルを取得した。改正告知は[2025年ダイヤ改正](https://kotsu.city.kobe.lg.jp/news/information/subway/20250315_subway/)も参照。

取得日: 2026-10-26 JST。取得時刻は各ファイルにUTC ISO形式で記録。独立資料レビュー日: 2026-10-26 JST。取得後に検査・証拠を再確認した時刻を `checkedAt = 2026-10-25T17:17:32.000Z` として固定し、キャッシュ再解析や同一CSVの再取得だけでは延長しない。`validFrom` は2025-03-15、`validTo` は終了日未公表のため null。null は無期限の有効性保証を意味しない。アプリの30日再確認期限とは区別する。

公式HTMLの直接取得には403または202のチャレンジが返った。制限回避・認証偽装・反復アクセスは行っていない。検索経由の公式ページ本文にはクロール時点の遅れがあるため、「公式サイトをリアルタイムに全件再確認した」とは扱わない。live CKANからのCSV取得と既存レビュー済みSHA-256一致は確認した。

個々の発着時刻という事実と、原表・データベース・ウェブサイトの利用条件は別に扱う。今回の一括データは明示されたオープンデータライセンスに従って加工・出典表示する。座標は既存のOpenStreetMap取得物を利用し、元ノードURLを各駅に保持する（ODbL、[著作権/帰属](https://www.openstreetmap.org/copyright)）。新規大量OSM取得はしていない。公式時刻表PDF/HTMLの丸ごと再配布はしていない。

## verified の根拠と限界

生成器が付けるフラグ自体は根拠にしない。以下が通った場合だけ56表を出力する。

1. 原CSVのSHA-256が固定した4つのレビュー済みハッシュに一致。改版・ファイル差替え時は停止し、新規取得物だけを保存する。
2. 全CSVで「始発駅」「行先駅」、全行の列数、17駅の過不足と重複を検査。
3. 列車ごとに始発/終着が存在し、進行方向の順序が正しく、その間に空欄がなく、区間外には時刻がないことを検査。列内時刻が逆転しないことも検査する。
4. 駅ごとに発車時刻の整列、時刻/行先の重複、日跨ぎ、短区間列車を検査。終着駅の時刻は到着として除く。谷上東行・西神中央西行の「発車表」は生成しない。
5. 学園都市・妙法寺の既存8表、全1,318発車が新しい変換結果と完全一致。既存の固定始発/昼/終電サンプルも一致。
6. 追加13表に対する39の始発/昼/終電アンカーを、CSV変換とは独立に読み取った公式HTML本文と照合。新神戸4表、県庁前4表、名谷4表、谷上平日西行1表。行先記号も確認。URLと期待値をJSON/コードに固定。

独立照合資料: [新神戸](https://kotsu.city.kobe.lg.jp/subway/timetable1/shinkobe/)、[県庁前](https://kotsu.city.kobe.lg.jp/subway/timetable1/kenchomae/)、[名谷](https://kotsu.city.kobe.lg.jp/subway/timetable1/myodani/)、[谷上](https://kotsu.city.kobe.lg.jp/subway/timetable1/tanigami/)。全駅全便を別資料と照合したわけではない。構造検査は元資料自体の誤りを証明・否定できない。各表の注記にもこの範囲を表示する。

原資料の保管範囲: 原CSV4本はダウンロードした全バイトとSHA-256、CKANカタログJSON、取得メタデータをローカルキャッシュへ保存。HTMLは検索ツールが提示した公式ページ本文を読み取ったもので、サーバーから取得したHTML全バイトやHTMLのSHA-256は保存できていない。独立照合で読み取った39アンカー・URL・照合方式・レビュー日を検証JSONに保存し、検索出力はこの作業のツール履歴に残る。CSV全バイトの再現性とHTMLレビューの保存粒度は同じではない。

県庁前西行の検索経由PDFテキストでは12:02、公式HTMLでは12:01という差が出た。CSVはHTMLの12:01と一致した。PDFの画像はこの環境で確認できていないため、PDF抽出テキストだけを根拠にCSVを補正していない。発見した差と検証方法の限界を保持する。

## 更新手順

```powershell
# 原データが存在するときのオフライン再生成。確認日は更新されない。
node scripts/import-kobe-expanded.mjs

# 公式CKAN 1回 + 一括CSV4本だけを取得。CSVの間は1.2秒空ける。
node scripts/import-kobe-expanded.mjs --refresh

npx vitest run tests/kobe-expanded.test.ts tests/municipal.test.ts
```

新しい取得物は `.cache/kobe-expanded/<UTC timestamp>/` に保存する。既存の原データは上書きしない。派生JSONの前版も `.cache/kobe-expanded/output-history/<UTC timestamp>/` に保存する。更新途中の失敗時は `latest.json` の成功スナップショットを維持し、アプリJSONを生成しない。新ハッシュ検出時はレビューを省いて固定値を更新しない。

改正時は、公式カタログの最新版・ライセンスと告知の適用日を確認し、旧新CSVの列・駅・時刻/行先差分を確認する。終端/短区間/新神戸/平休/24時以降の例外を重点レビュー。独立サンプルとレビュー時刻を根拠付きで更新してから生成する。再取得が成功したという理由だけで `OFFICIAL_REVIEWED_AT` を延長しない。次の改正日が公表されたら旧版の `validTo` を設定し、適用期間を分離する。
